# A.I. The Shooter — Official Website

Official website for A.I. The Shooter (rapper / artist / creator):
SoundCloud player, YouTube videos, photo gallery, and social links.

Rebuilt in November 2026 by 103 Software Solutions LLC from the original
site (Isaac's first build) after the original domain lapsed — same content,
one consistent brand system: black and steel from the artist's emblem,
single amber accent, poster-style display type.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build   # outputs dist/ (relative base — works from any path)
```

The `gh-pages` branch holds the built site and is what GitHub Pages serves.
